**IronRuby 4.0.2** runs a Rails 8.1 app with SQLite on Windows, is about 1.2 times as fast
across IronRuby's micro benchmarks and starts in 1.25 s instead of 1.86 s, serves TLS through
net/http and Puma, and calls .NET the way Ruby 4 code is written. The legacy parser and the
Ruby 1.9 library are gone. The interpreter is now called `ironruby`, as JRuby's is `jruby`,
and every download comes with a signed build provenance attestation.

### Download

Self-contained: unpack one and run `./ironruby`, `./irb.sh` and `./igem.sh` - on Windows
`ironruby.cmd`, `irb.cmd` and `igem.cmd`. No .NET to install. `ir.sh` and `ir.cmd` still
work.

- **Windows x64**: `ironruby-4.0.2-win-x64.zip`, with Windows Forms, WPF, `ironrubyw.exe`
  and `Samples\Notepad\notepad.cmd`
- **Linux x64**: `ironruby-4.0.2-linux-x64.tar.gz`
- **macOS arm64**: `ironruby-4.0.2-osx-arm64.tar.gz`, built in CI, not tested there

`SHA256SUMS` lists the checksums. Each archive and `SHA256SUMS` has a signed build
provenance attestation, which says which workflow built it, from which commit, in which run:

```
gh attestation verify ironruby-4.0.2-linux-x64.tar.gz --repo Largo/ironruby
```

### New

- **Rails 8.1 with SQLite on Windows** (#34). `gem install rails`, `rails new`,
  `bundle install`, a scaffold, migrations, importmap with Turbo and Stimulus, and
  `bin/rails server` on Puma and sqlite3, as a Windows user would run them. It took
  `File#flock` on Windows, IO readiness without libc, Bundler's `platforms:` for IronRuby,
  binstubs that start IronRuby, and a dozen more fixes, listed in
  [Docs/rails-on-windows.md](https://github.com/Largo/ironruby/blob/v4.0.2/Docs/rails-on-windows.md).
  In a sweep of popular gems on Windows, 81 give the same output as CRuby byte for byte,
  among them rubocop, standard, rspec, pry, prawn, sprockets and listen.
- **Faster** (#22). IronRuby's 50 micro benchmarks run in 11.2 s instead of 26.1 s (geometric
  mean 1.21x): switching fibers is 7.1x as fast, `raise`/`rescue` 5.5x, keyword arguments
  about 9x, near CRuby's time. `ironruby -e 1` starts in about 1.25 s instead of 1.86 s.
- **TLS** (#28, #32, #33). `OpenSSL::SSL::SSLSocket` is non-blocking, so net/http's open,
  read and write timeouts work unmodified, for RubyGems too; certificates are verified
  against the context's CAs, with `verify_callback`. Puma serves `ssl://`.
- **Calling .NET** (#26, #31, #25). Keyword arguments bind to parameters by name, a block
  goes to the trailing delegate parameter (`list.Sort { |a, b| b <=> a }`, `Task.Run { }`),
  and the split .NET libraries load on demand, so `System::Console` just works. `super` in
  `initialize` runs the .NET base constructor. Stores into a boxed struct's field stick,
  zlib works on Windows, and so do `Process.kill` and `File::NULL`.
- **Ruby 4.0** (#23, #30). Many core classes now behave as CRuby 4.0's, found by running
  IronRuby and CRuby side by side and by ruby/spec. `Rational` and `Complex` are ports of
  CRuby 4.0's, and `Pathname` is CRuby 4.0's own.
- **prism 2.0** (#27). IronRuby follows ruby/prism's new serialization, and deeply nested
  code runs instead of overflowing the stack.

### Changed

- **The interpreter is `ironruby`** (#35), and so is RbConfig's `ruby_install_name`: the
  binstubs Bundler and Rails write start `#!/usr/bin/env ironruby`, a line Ruby runs as
  Ruby. `ir`, `ir.sh` and `ir.cmd` stay as its short name. On Windows, `ironrubyw.exe` is
  the same interpreter without a console window, as `rubyw.exe` is CRuby's; the Notepad
  sample starts with it.
- **`ironruby` with no script reads the program from stdin** (#35), as `ruby` does, at a terminal
  too, and `$0` is `"-"`. It used to start the DLR's interactive console; irb is `irb` or
  `iirb`.
- **Prism is the only parser** (#34). `-X:UsePrism` is still accepted and does nothing.
- **Gems written for prism 1.x or bigdecimal 2.x and 3.x activate** with the built-in
  prism 2.0 and bigdecimal 4.0 (#34): rubocop, standard, minitest 6 and prawn among them.
- **Windows**: file names, `ENV`, `ARGV` and the default external encoding are UTF-8, as in
  CRuby; `Dir.pwd` keeps a short 8.3 path as it was given; `Dir.home` uses `/`; local time
  follows daylight saving time (#19).
- **The Ruby 1.9 library is removed** (#29, #30), including its `cgi` code with known
  vulnerabilities and a `win32/sspi` that wrote past its buffers on 64-bit Windows.

### Security and auditing

- Signed build provenance for every published file, made by GitHub's `actions/attest` in
  the job that built it (#36).
- The repository holds no programs any more: 18 test fixtures and sample DLLs from 2016,
  which nothing built or shipped, are gone, and CI fails if one comes back (#36). The
  upstream checkouts the build uses are pinned (#29).
