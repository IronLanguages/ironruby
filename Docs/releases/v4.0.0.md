**IronRuby is back: Ruby 4.0 on .NET 8 and 10.** The last release of IronRuby was 1.1.3,
for Ruby 1.9.2 on .NET Framework 4, in 2011. 4.0.0 implements Ruby 4.0, parses it with
[prism](https://github.com/ruby/prism) (CRuby's own parser), and runs on Linux, Windows and
macOS.

[![IronRuby 4.0, the 55-second launch video](https://raw.githubusercontent.com/Largo/ironruby/v4.0.0/media/launch/poster.jpg)](https://github.com/Largo/ironruby/releases/download/v4.0.0/ironruby-4-launch.mp4)

### Download

The archives below are self-contained: unpack one and run `ir.sh` / `ir.cmd`, `irb`,
`igem`. No .NET to install.

- **Windows x64**: `ironruby-4.0.0-win-x64.zip`, with Windows Forms, WPF and
  `Samples\Notepad\notepad.cmd`, a Windows Notepad written in Ruby
- **Linux x64**: `ironruby-4.0.0-linux-x64.tar.gz`
- **macOS arm64**: `ironruby-4.0.0-osx-arm64.tar.gz` (untested)

`SHA256SUMS` lists the checksums; `ironruby-4-launch.mp4` is the launch video.

### What is in it

- **Ruby 4.0 syntax, read by prism**: pattern matching, endless methods, `it`, keyword
  arguments, `...` forwarding. prism's syntax tree is decoded by a generated C# loader
  (152 node classes) and lowered onto IronRuby's AST and the DLR.
- **ruby/spec at CRuby 4.0.6**: `spec/language` 2,934 examples and `spec/library` 6,398,
  both with 0 failures; `spec/command_line` and `spec/security` at 0 as well; `spec/core`
  21 of 23,136, 20 of them `ObjectSpace.each_object`.
- **A method JIT and OSR**, on by default, specializing on the types a program uses:
  integer and float loops, `fib` and `mandelbrot` run in 0.27–0.74× CRuby's time. The
  geomean over all 50 benchmarks is 3.25×: method calls, strings and arrays are 2–4×, and
  `raise` and fibers are far behind.
- **irb 1.16.0 and reline 0.6.3**, the ones CRuby 4.0 ships, with highlighting, completion
  and history. **RubyGems 4.0.16 and Bundler**, installing over real TLS. Ruby 4.0's standard
  library and its pure-Ruby bundled gems ship in the box.
- **Rails 8.1 boots** and serves requests through Rack, with nokogiri, a C extension,
  stubbed; ActiveRecord has no adapter yet, as `sqlite3`, `pg` and `mysql2` are native.
- **.NET is right there**: `require "System.Windows.Forms"` or `"PresentationFramework"`.
  [`Samples/Notepad`](https://github.com/Largo/ironruby/tree/v4.0.0/Samples/Notepad) is
  Windows Notepad in 1,365 lines of Ruby, with a test that drives it in CI.
- **`irubyc`** packages a Ruby program as an application, as one executable
  (`--single-file`), or as a plugin DLL a .NET host loads (`--library`).

### Not yet

`zlib`, Win32OLE and readline on Windows, C extensions in general (no `nokogiri`, no
database drivers), and macOS is built but untested. The
[README](https://github.com/Largo/ironruby#status) has the full status.

Thanks to everyone who built IronRuby at Microsoft and in IronLanguages, and to the prism
and ruby/spec projects, without which none of this would be measurable.
